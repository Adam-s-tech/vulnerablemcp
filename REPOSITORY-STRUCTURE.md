# Repository Structure

## Source Files

### Data
- `data/vulnerabilities.json` - Vulnerability database (edit this to add vulnerabilities)

### Templates
- `src/templates/partials/head.ejs` - Shared `<head>` section (meta tags, GA, CSS)
- `src/templates/partials/header.ejs` - Shared navigation header
- `src/templates/partials/footer.ejs` - Shared footer with links and scripts
- `src/templates/pages/index.ejs` - Home page with vulnerability cards
- `src/templates/pages/about.ejs` - About page
- `src/templates/pages/security.ejs` - MCP Security guide
- `src/templates/pages/etdi-security.ejs` - ETDI Security framework page
- `src/templates/pages/404.ejs` - 404 error page

### Static Assets
- `assets/css/style.css` - Shared stylesheet
- `assets/js/main.js` - Client-side JavaScript
- `favicon.ico` / `favicon.svg` - Site icons
- `*.png` - Diagrams and images (for ETDI security page)

### Build & Scripts
- `build.js` - Main build script (EJS templates + JSON data -> HTML)
- `server.js` - Local development server (serves from `dist/`)
- `scripts/validate.js` - JSON schema validation for vulnerability data
- `scripts/migrate-md-to-json.js` - Migration tool from old markdown format

### Configuration
- `package.json` - Node.js dependencies and scripts
- `.github/workflows/deploy.yml` - GitHub Actions CI/CD workflow
- `.gitignore` - Git ignore rules

### Documentation
- `README.md` - Main project documentation
- `UPDATE-GUIDE.md` - Guide for adding new vulnerabilities
- `REPOSITORY-STRUCTURE.md` - This file

### Legacy (kept for reference)
- `vulnerabilities.md` - Original markdown vulnerability database
- `update-stable.js` - Old regex-based HTML injection build script
- `rebuild_and_deploy.sh` - Old manual deployment script

## Output
- `dist/` - Built static site (git-ignored, generated by `build.js`)

## Workflow

1. **Edit data**: Add entries to `data/vulnerabilities.json`
2. **Validate**: Run `npm run validate`
3. **Build**: Run `npm run build` to generate HTML in `dist/`
4. **Preview**: Run `npm run dev` to serve locally
5. **Deploy**: Push to `main` -- GitHub Actions auto-deploys to GitHub Pages
